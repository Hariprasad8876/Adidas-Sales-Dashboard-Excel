# Adidas-Sales-Dashboard-Excel
Performed data cleaning and validation using Python (Pandas, NumPy) to ensure data accuracy and consistency. Developed an interactive sales dashboard in Excel using Pivot Tables, Pivot Charts, KPI cards, and Slicers to analyze sales performance by retailer, category, channel, and region.
Project: Adidas Sales Dashboard

Objective:
To clean and analyze Adidas sales data using Python and create an interactive Excel dashboard to monitor sales performance, profitability, and product trends across different retailers, regions, categories, and sales channels.

Tools Used:
- Python (Pandas)
- Excel
- Pivot Tables
- Pivot Charts
- Slicers

Project Workflow:
1. Imported raw Adidas sales data.
2. Cleaned and validated data using Python.
3. Created pivot tables in Excel.
4. Built an interactive dashboard with KPIs, charts, and slicers.
5. Analyzed sales performance by retailer, category, channel, and region.

Key Insights:

• West Gear generated the highest sales among all retailers.
• In-store sales contributed the largest share of total sales compared to Online and Outlet channels.
• Men's Street Footwear was the top-performing product category.
• Sales showed an upward trend during the middle months of the year, indicating seasonal demand patterns.
• Certain regions contributed significantly more revenue than others, helping identify high-performing markets.
• Profit margin remained healthy, indicating strong profitability across sales operations.
